เราจะสร้าง **ANS ICT Hub** เว็บรวมสื่อการสอนวิชา ICT ของฉัน (ครู ICT ป.3–ป.4 โรงเรียนอำนวยศิลป์) ให้นักเรียนเลือกห้อง → เลือกชื่อเล่น (ไม่ต้อง Login) → เลือกใบงาน/เกมเหมือนเลือกเกม และงานติดตัวนักเรียนข้ามเครื่องได้ มีมุมครูสำหรับเปิด/ปิดกิจกรรม ดูใครส่งงาน แชร์ผลงาน และจัดการรายชื่อ

ในโฟลเดอร์ `handoff/` มี:
- `SCOPE.md` — สโคปทั้งหมดที่ตกลงแล้ว (อ่านทั้งไฟล์ก่อน)
- `mock/` — ไฟล์ Mock หน้าจอที่ตกลงแล้ว (.dc.html แต่ละหน้า ดูโครงและสี)
- `legacy/worksheet/` — ใบงานเดิม (template4.html, gen2.py = config, gen4.py = ตัวสร้าง, share_template.html = หน้าแชร์ครู)
- `legacy/games/` — เกม 2 เกม (adventure.html, popup_game.html)
- `legacy/apps-script/` — Apps Script อ้างอิง (ตัวจริงฉันจะคัดลอกมาให้)
- `legacy/tests/` — ตัวอย่างสคริปต์ Playwright ที่เคยใช้ทดสอบ

สิ่งที่ขอตอนนี้:
1. อ่าน SCOPE.md, ดู mock และโค้ดเดิมใน legacy ให้เข้าใจ
2. สรุปให้ฉันว่าเข้าใจอะไร และเสนอ **แผน Phase 1** แบบละเอียด: โครงโฟลเดอร์ repo, รูปแบบ config ของกิจกรรม, API ของ Apps Script เวอร์ชันใหม่, และสิ่งที่ต้องถามฉันก่อน (ดูหัวข้อ 10 ใน SCOPE)
3. **ยังไม่ต้องเขียนโค้ด** จนกว่าฉันยืนยันแผน
