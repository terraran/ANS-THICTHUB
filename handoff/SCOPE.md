## 1. เป้าหมาย

เว็บเดียวรวมสื่อการสอนวิชา ICT (เว็บ "THAI ICT") ให้นักเรียนเข้าแล้ว **เลือกสิ่งที่ต้องการเหมือนเลือกเกม** แทนการแจกไฟล์ HTML ทีละไฟล์ และให้ **งานติดตัวนักเรียน** โดยไม่ต้อง Login

- ผู้ใช้: นักเรียน ป.3 (Y3) และ ป.4 (Y4) · ครูผู้สอน (มุมครู)
- ระดับชั้น: Y3–Y4 ก่อน · โครงต้องเพิ่ม Y5–Y6 ได้ด้วยการเพิ่มข้อมูล ไม่ต้องแก้โค้ด
- ภาษา: ไทย/อังกฤษ สลับได้ทุกหน้า (TH/EN)
- อุปกรณ์หลัก: คอมพิวเตอร์ห้อง ICT (จอแนวนอน) · ต้องใช้บนแท็บเล็ต/จอเล็กได้ด้วย

## 2. โครงสร้าง Repo และการ Deploy

- **Repo เดียว** (ชื่อเสนอ `ans-ict-hub`) · deploy ด้วย **GitHub Pages**
- ย้ายใบงาน Y3 และ Y4 ที่ตอนนี้อยู่คนละ repo เข้ามารวม · ใช้ template ใบงาน + ระบบส่งงานร่วมกัน
- แนะนำ **static site ไม่มี build step** (HTML + vanilla JS + JSON config) เพื่อให้ครูแก้เนื้อหาเองได้และ Pages ไม่พัง · ถ้าเลือกใช้ build tool ต้องมีเหตุผลชัดเจนและ GitHub Action ที่ไม่ยุ่งกับ repo อื่น
- **คีย์บอร์ดเควส (ANSTH-Typing) อยู่ repo เดิม ไม่ย้าย** · Hub แค่ลิงก์ไป (ห้ามแตะ build Actions ของ repo นั้น)
- **ห้ามใส่รหัสครู (teacher key) ใน repo** ไม่ว่าไฟล์ไหน · ครูพิมพ์รหัสตอนเข้ามุมครูเท่านั้น

## 3. หลังบ้าน: Google Sheet + Apps Script ตัวเดียว

ระบบเดิมใช้ Sheet 1 ไฟล์ + Apps Script web app (ดู `legacy/apps-script/`) · Hub ขยายต่อจากตัวเดิม

### 3.1 แท็บใน Sheet (เสนอ)
| แท็บ | คอลัมน์ | หมายเหตุ |
|---|---|---|
| `Roster` | room, nickname, active, order | ชื่อเล่นอย่างเดียว ห้ามชื่อจริง/นามสกุล · ชื่อซ้ำในห้องครูตั้งให้ต่าง เช่น "มายด์ ก" |
| `Activities` | id, level, week, kind (sheet/game/link), title_th, title_en, path, frq_th, frq_en | ข้อมูลการ์ดในคลังกิจกรรม · หรือเก็บเป็น JSON ใน repo ก็ได้ (ตัดสินใจตอนทำ) |
| `Unlocks` | room, activityId, open | ครูเปิด/ปิดกิจกรรมรายห้อง |
| `Drafts` | room, nickname, activityId, json, updatedAt | งานที่ทำค้าง (autosave) |
| `Submissions` | คอลัมน์เดิม + members (JSON array ของชื่อเล่น) | ต่อจากแถวที่ใบงานเดิมส่งอยู่แล้ว (ดู 3.3) |

### 3.2 API (Apps Script `doGet` / `doPost` แยกด้วย `action`)
นักเรียน (ไม่ต้องใช้ key):
- `GET action=roster&room=Y3.2` → รายชื่อเล่นของห้อง
- `GET action=state&room=..&name=..` → กิจกรรมที่เปิด + สถานะงานของเด็กคนนี้ (ยังไม่เริ่ม/ทำค้าง/ส่งแล้ว) + draft
- `POST action=draft` → บันทึกงานที่ทำค้าง (debounce ประมาณ 5–10 วินาที และตอนเปลี่ยนขั้น)
- `POST action=submit` → ส่งงาน · ถ้าทำคู่ ให้นับสถานะ "ส่งแล้ว" ให้ทุกคนใน members

ครู (ต้องมี `key` ตรงกับใน Script):
- `GET action=dashboard&room=..` → ตารางนักเรียน × กิจกรรม
- `GET action=submissions&level=..&week=..` → ข้อมูลหน้าแชร์ผลงาน (ตัวเดิมใช้ `?key=&level=&week=`)
- `POST action=setUnlock` / `action=roster` (เพิ่ม/แก้/ซ่อนชื่อ, วางหลายชื่อ)

ข้อจำกัดที่รู้แล้ว:
- POST จากเบราว์เซอร์ใช้ `fetch(..., {mode:'no-cors', headers:{'Content-Type':'text/plain'}})` → อ่าน response ไม่ได้ · การอ่านข้อมูลทั้งหมดใช้ GET (Apps Script คืน JSON ผ่าน redirect ได้)
- ใช้ `LockService` ตอนเขียน Sheet (ตัวเดิมทำอยู่แล้ว)
- ทุกครั้งที่แก้ Script ต้อง Deploy → Manage deployments → New version (URL เดิม)

### 3.3 แถวที่ใบงานเดิมส่ง (ต้องเข้ากันได้ย้อนหลัง)
`[timestamp, level, week, title, room, names, lang, score, wrong, exact, chosen, hesCard, reason, JSON{v:2, act, round, place, signs, hes, reason, fr}, fr, round]`
- หน้าแชร์ผลงานอ่าน `r[13]` (JSON) · ถ้าเปลี่ยนโครง ให้ bump `v` และรองรับ v2 ต่อ

## 4. ฝั่งนักเรียน (ไม่ต้อง Login)

ลำดับหน้า (ตาม Mock):
0. **หน้าแรก** — การ์ด Thumbnail ใหญ่ 2 ใบ: **THAI ICT** (ใบงาน + เกม) และ **พิมพ์ไทย** (ลิงก์คีย์บอร์ดเควส เปิดแท็บใหม่) · ปุ่ม TH/EN · ลิงก์ "มุมครู" มุมล่าง
1. **เลือกห้อง** — ปุ่มห้องแบ่งตามระดับชั้น (Y3 สีฟ้า / Y4 สีคราม)
2. **เลือกชื่อ** — การ์ดชื่อเล่น + วงกลมตัวอักษรแรก · **ไม่มีรหัส** (ยอมรับว่าเด็กกดชื่อเพื่อนได้ ครูดูแลในห้อง)
3. **คลังกิจกรรม** — แถบ **ใบงาน / เกม** · การ์ดแต่ละใบมีสถานะ: ส่งแล้ว ✓ / ทำค้างไว้ / ยังไม่เริ่ม / 🔒 ครูยังไม่เปิด · แถบบนแสดงชื่อ ห้อง ลิงก์ "เปลี่ยนชื่อ" "หน้าแรก" และความคืบหน้า (ส่งแล้วกี่ใบ)
4. **ในใบงาน** (หัวข้อ 5)

กติกา "งานติดตัว":
- **สถานะงาน** และ **ทำต่อจากที่ค้าง** ต้องตามเด็กไปทุกเครื่อง (มาจาก Sheet ไม่ใช่ localStorage)
- localStorage ใช้แค่จำห้อง/ชื่อ/ภาษาที่เลือกล่าสุดในเครื่องนั้น (ห่อ try/catch)
- **ทำงานคู่**: ในใบงานกด "+ ทำกับเพื่อน" → เลือกเพื่อนจากรายชื่อห้องเดียวกัน · ส่งครั้งเดียว นับให้ทั้งคู่
- ไม่เก็บสถิติพิมพ์ไทย (คีย์บอร์ดเควสเป็นลิงก์เฉย ๆ)

## 5. ใบงาน (template กลาง)

ใช้ template เดียวทุกสัปดาห์/ทุกชั้น เนื้อหามาจาก config (ดู `legacy/worksheet/gen2.py` = config Y3/Y4 สัปดาห์ 1 · `gen4.py` = ตัวสร้างไฟล์)

ของที่มีอยู่แล้วในใบงานเดิม (ต้องคงไว้): จอ 1600×900 scale ให้พอดีจอ ไม่ต้องเลื่อน · ลากหรือแตะการ์ดลง Tree Map 2 กลุ่ม · การ์ด 16 ใบ · ป้ายสัญญาณใต้การ์ด · เลือกการ์ดที่ลังเล + เหตุผล · ตรวจคำตอบ/แสดงคำอธิบาย · รอบที่ (round) · แก้แล้วส่งใหม่ · โหมด TH/EN · ปุ่มเกมหลังส่งสำเร็จ (Y3)

สิ่งที่เปลี่ยนเมื่ออยู่ใน Hub:
- **ตัดขั้นลงชื่อ** — รับ room / name / partner จาก Hub
- แถบหัว **สีน้ำเงินเข้ม #0b2545** (สีเดียวกับ Hub) · มีปุ่มกลับคลังกิจกรรม · ป้าย "บันทึกอัตโนมัติแล้ว HH:MM" · ชื่อเด็ก + ปุ่ม "+ ทำกับเพื่อน"
- พื้นที่ทำงานพื้นเทาอ่อน #f1f5f9 · การ์ดบนพื้นขาว
- **4 ขั้น**:
  1. จัดกลุ่ม (Tree Map)
  2. หาสัญญาณ
  3. ให้เหตุผล — กดการ์ดที่ลังเลที่สุด + พิมพ์ "อะไรทำให้เราคิดแบบนั้น?" → ปุ่ม "ไปขั้นต่อไป ➜"
  4. **Frame of Reference (ไม่บังคับ)** — หน้าแยก มีกรอบใหญ่กรอบเดียว คำถามตัวใหญ่ + **ช่องพิมพ์อิสระช่องเดียว** (placeholder ประโยคเริ่ม เช่น "เรารู้เพราะ...") · **ไม่มีปุ่มตัวเลือก** · ปุ่ม: ◀ ย้อนกลับ / **ข้าม แล้วส่งเลย** / **ตรวจคำตอบและส่งให้ครู ✔** (ทั้งสองปุ่มส่งงาน ต่างกันแค่ fr ว่างหรือไม่)
- **คำถาม FoR ครูตั้งได้ใบงานละ 1 ข้อ** (ใน config) · ค่าเริ่มต้นจากคำถามหลัก 3 ข้อของโรงเรียน (เอกสาร "Thinking Maps – New staff 2025"):
  1. รู้สิ่งเหล่านั้นได้อย่างไร (How do you know what you know?) → ใบงาน: "เรารู้ได้อย่างไรว่าการ์ดไหนอยู่กลุ่มไหน?"
  2. อะไรที่มีอิทธิพลกับข้อมูลใน map (What is influencing the information on your map?)
  3. ทำไมข้อมูลเหล่านั้นจึงสำคัญ (Why is this information important?)
- เก็บคำถามที่ใช้ (`frq`) ไว้ใน JSON ที่ส่งด้วย · คำตอบ FoR แสดงในหน้าแชร์ผลงาน
- **ไม่ใส่ FoR ในแผนการสอน** (ครูตัดสินใจแล้ว)

## 6. เกม

- **ผจญภัยป่ามหัศจรรย์** (`legacy/games/adventure.html`) — 3 ด่าน · 3 โหมด (ง่าย/ปกติ/ยาก) · เกมหยุดทุกครั้งที่ป๊อปอัปขึ้น · มีปุ่ม "↩ กลับใบงาน" เมื่อเปิดใน iframe (ฟัง `postMessage({lang})`, ส่ง `'closeGame'` กลับ)
- **ปิดป๊อปอัปให้ทัน 60 วินาที** (`legacy/games/popup_game.html`)
- เกมเป็นแบบเล่นเฉย ๆ **ไม่เก็บคะแนน**
- ใน Hub: เปิดจากแถบ "เกม" ได้ (ถ้าครูเปิดให้ห้องนั้น) และยังมีปุ่มเล่นเกมหลังส่งใบงานสำเร็จเหมือนเดิม

## 7. มุมครู (ต้องใส่รหัสครู)

หน้าใส่รหัส → เก็บใน sessionStorage (ห่อ try/catch) · เมนูซ้าย 4 หัวข้อ · เลือกห้องด้านบน
1. **ตารางส่งงาน** — สรุป ส่งแล้ว / ทำค้าง / ยังไม่เริ่ม + ตารางรายคน × ใบงาน + คอลัมน์ "ทำคู่กับ"
2. **เปิด/ปิดกิจกรรม** — สวิตช์รายกิจกรรมรายห้อง
3. **แชร์ผลงาน** — ย้ายจากหน้าแชร์เดิม (`legacy/worksheet/share_template.html`): จัดกลุ่มเป็นรอบ, ปุ่มรอบ, เทียบ 2 ชิ้น, ซ่อนชื่อ, การ์ดที่ผิดบ่อย, คำตอบ FoR, บันทึก PNG (html2canvas 1.4.1 จาก cdnjs)
4. **รายชื่อนักเรียน** — เพิ่ม / แก้ / ซ่อนชื่อ · วางหลายชื่อทีเดียว

## 9. ลำดับการทำ (Phase)

| Phase | งาน | เสร็จเมื่อ |
|---|---|---|
| 1 | โครง repo + Pages · หน้าแรก / เลือกห้อง / เลือกชื่อ / คลังกิจกรรม · ย้ายใบงานสัปดาห์ 1 (Y3/Y4) + เกม 2 เกมเข้ามา · ลิงก์คีย์บอร์ดเควส · Apps Script เวอร์ชันใหม่ (roster, state, submit) | เด็กเลือกห้อง→ชื่อ→ทำใบงาน→ส่งเข้า Sheet ได้ และสถานะ "ส่งแล้ว" ขึ้นในคลัง |
