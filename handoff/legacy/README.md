# legacy — โค้ดเดิมก่อนทำ Hub

## worksheet/
- `template4.html` — ใบงานตัวล่าสุด (จอ 1600×900, ขั้น 0–3, ส่งเข้า Sheet, แก้แล้วส่งใหม่)
- `gen2.py` — config เนื้อหา Y3 / Y4 สัปดาห์ 1 (การ์ด 16 ใบ, ป้ายสัญญาณ, ข้อความ TH/EN) · ไฟล์นี้อ่าน `template2.html` ตอน import จึงแนบไว้ด้วย (ไม่ได้ใช้แล้ว)
- `gen4.py` — สร้างไฟล์ใบงาน + หน้าแชร์ครู: `python3 gen4.py <endpoint> <outprefix>` · ฝังเกมผจญภัยลงใบงาน Y3 (ปุ่มเล่นหลังส่ง)
- `share_template.html` — หน้าแชร์ผลงานของครู (`__KEY__` ถูกแทนด้วยรหัสครูตอนสร้าง — ห้าม commit ไฟล์ที่สร้างแล้ว)
- `endpoint.txt` — URL Apps Script ปัจจุบัน (อยู่ในไฟล์ใบงานนักเรียนอยู่แล้ว ไม่ใช่ความลับ)
- `key.txt` — **ค่าตัวอย่าง** ใส่รหัสจริงในเครื่องเท่านั้น

## games/
- `adventure.html` — ผจญภัยป่ามหัศจรรย์ (3 ด่าน, 3 โหมด, เกมหยุดเมื่อป๊อปอัปขึ้น, รองรับ iframe: ปุ่มกลับใบงาน)
- `popup_game.html` — ปิดป๊อปอัปให้ทัน 60 วินาที

## tests/ (Playwright, Chromium)
- `testemb.js` — ทดสอบปุ่มเกมในใบงาน Y3 · `test10.js`, `advtest2.js` — autopilot เล่นเกมผจญภัยทุกโหมด
- path ในไฟล์อ้างโฟลเดอร์เดิม ต้องแก้ก่อนใช้

## apps-script/
- `Code_reference.gs` — เขียนใหม่จากบันทึก ให้ใช้ตัวจริงจาก Sheet ของครูแทน
